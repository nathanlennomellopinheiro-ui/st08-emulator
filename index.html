ABOUT THE PROJECT

ST.08 Emulator is an independent experimental project focused on learning about executable formats, console architecture and software compatibility.

This is a research project, not a finished emulator.

The current prototype inspects ELF64 headers and writes diagnostic logs. CPU execution, PS5 system modules and game graphics are not implemented yet.
